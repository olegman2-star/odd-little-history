Privacy Policy

Odd Little History Uploader · effective 31 October 2026

Odd Little History Uploader is a private tool used only by the owner of the Odd Little History YouTube channel to publish that channel's own videos.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos, set their titles, descriptions and publish times, post a comment on those videos, and read basic statistics for the owner's own channel.

What it stores

The sign-in token is stored only on the owner's own computer. The tool does not collect, store, sell or share data about viewers or any other Google users, and it does not use cookies or analytics.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: through the channel's About page.
